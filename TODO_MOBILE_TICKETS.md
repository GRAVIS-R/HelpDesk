# TODO_MOBILE_TICKETS.md

## Что сделано (история изменений)

### 1) Попытка унификации разметки и правки под мобильный режим
В файле: `views/admin/tickets/AllTickets.vue` была выполнена правка DOM-структуры вокруг блока с фильтрами.

Цель: подготовить UI для мобильного/десктопного режима (скрывать/показывать часть UI-фильтров в зависимости от ширины экрана).

### 2) Изменение отображения блока фильтров
Добавлено условие отображения блока фильтров (компонент `TicketFilters`) по флагу `isMobile`.

- Было (пример логики):
  - блок фильтров всегда отображался

- Стало (логика):
  - `TicketFilters` оборачивается в условие `v-if="!isMobile"`
  - т.е. блок фильтров показывается только на десктопе (когда `isMobile === false`).

Это связано с тем, что страница уже переключает `viewMode` между `'cards'` и `'table'`.

### 3) Восстановление сломанной структуры `<template>`
В процессе точечных правок разметка `template` в `AllTickets.vue` получила парсинг-ошибку (`x-invalid-end-tag`).

Как исправлено:
- возвращена корректная структура контейнеров:
  - корневой контейнер: `<div class="all-tickets-root">...
  - внутри него: `<div class="all-tickets-page">...
- устранены лишние/недостающие закрывающие `</div>`

> Итог: файл приведён к корректному парсингу (без ошибок invalid end tag).

## Как работает мобильный режим (контекст для дальнейших правок)
В `AllTickets.vue` уже реализовано:
- `isMobile = ref(false)`
- `checkMobile()`:
  - `isMobile.value = window.innerWidth <= 900`
  - `viewMode.value = isMobile.value ? 'cards' : 'table'`
- `onMounted()`:
  - подписка на `resize`
  - вызов `initializeByRoute()`
  - загрузка таблицы и счетчиков
